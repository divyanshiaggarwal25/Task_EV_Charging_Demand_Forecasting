# Task 01: EV Charging Demand Forecasting & Analytics

Professional data analytics project focused on cleaning EV charging datasets, building a demand forecasting model in Python, and designing an interactive Power BI dashboard.

## Project Structure
- `Python/`: Contains the Jupyter notebook (`ev_demand_forecasting_task1.ipynb`) and processed CSV files (`daily_ev_demand_cleaned.csv`, `ev_demand_forecast_365days.csv`).
- `PowerBI/`: Contains the interactive Power BI dashboard (`ev_demand_dashboard.pbix`).

## Tools & Technologies
- **Python** (Pandas, NumPy, Time-Series Forecasting)
- **Power BI Desktop** (Data Modeling, Line Charts, KPI Visuals)
- **GitHub** (Version Control & Submission)
